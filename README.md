# 配信用リアルタイム翻訳字幕

マイクの日本語音声を認識し、必要に応じてDeepLで英訳して、OBSなどのブラウザソースへ表示するWindows向けツールです。わんコメ、TanuEsa、OBSの一括起動も必要なものだけ選択できます。

LLMによる会話生成やLive2D制御は含みません。

## 初期設定

1. `setup.bat` を実行します。
2. ブラウザで `http://127.0.0.1:5000/setup` が開きます。
3. 使用する機能、マイク、DeepL、外部アプリのパスを設定します。
4. 「設定を保存」を押します。
5. 設定用サーバーを `Ctrl+C` で終了します。
6. `haishin.bat` を実行します。

設定は `config.json` に保存されます。このファイルにはDeepL認証キーが含まれるためGit管理対象外です。設定画面は保存済みのキーをブラウザへ返しません。キー欄を空欄のまま保存すると、現在のキーを維持します。

設定例は `config.example.json` です。通常は直接編集せずWeb設定画面を使用してください。

## 選択できる機能

- Google日本語音声認識
- DeepL英訳
- 日本語字幕の表示
- 英語字幕の表示
- わんコメの起動
- TanuEsaの起動
- OBS Studioの起動

無効にした外部アプリは、ファイルの存在確認も起動も行いません。翻訳サーバーは設定画面と字幕表示の基盤として常に起動します。

`setup.bat` が自動取得するのはPythonの依存パッケージだけです。OBS、わんコメ、TanuEsaは自動ダウンロードせず、利用者がインストールした実行ファイルを設定画面で指定します。

## 字幕表示

OBSのブラウザソースには次のURLを設定します。

```text
http://127.0.0.1:5000/
```

ポートを変更した場合はOBSのURLも同じポートへ変更してください。字幕画面には有効にした言語だけが表示されます。

## 通常起動

`haishin.bat` を実行してください。設定で有効にした外部ツールと翻訳サーバーが起動します。

ランチャーを終了すると、ランチャーが起動した管理対象プロセスも終了します。OBSには可能な限り通常終了を依頼してから、残りを終了します。

外部アプリを起動せずに設定パスだけ確認する場合：

```powershell
.\haishin_launcher.ps1 -ValidateOnly
```

## 音声認識の調整

- マイク名は部分一致で検索します。
- マイク番号を指定した場合は番号を優先します。
- 起動時の無音校正中は話さず、対象入力へBGMや読み上げ音声を送らないでください。
- 音声の語頭・語尾が欠ける場合は、無音校正、発話終了待ち、前後の無音を調整してください。

## 状態確認

翻訳サーバー起動後、次のURLで状態を確認できます。

```text
http://127.0.0.1:5000/health
```

設定画面は通常起動中も次のURLから開けます。保存した変更はランチャーの再起動後に反映されます。

```text
http://127.0.0.1:5000/setup
```

## 通信と保存

- 音声認識を有効にすると、音声がGoogle音声認識へ送信されます。
- DeepL翻訳を有効にすると、認識された日本語テキストがDeepLへ送信されます。
- 字幕履歴は保存せず、最新の字幕だけをメモリ上に保持します。
- 設定サーバーは `127.0.0.1` または `localhost` だけで待ち受けます。
